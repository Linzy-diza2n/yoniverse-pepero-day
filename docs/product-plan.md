## 서비스와 핵심 경험

요니버스는 연애 고민 커뮤니티 앱이다. 이번 프로젝트는 특정 시즌인 빼빼로데이를 위한 이벤트성 스핀오프 웹이다. 서비스명은 미정이다.

유저마다 블로그·미니홈피 같은 개인 공간과 고유 링크를 갖는다. 지인은 링크에 방문해 빼빼로 주기를 누르고, 디지털 빼빼로를 꾸미고 포장해 짧은 편지와 함께 보낸다. 친구·호감 있는 상대·연인에게 마음을 표현한다.

베이킹이나 조리 게임이 아니다. 유저의 노력은 인스타그램 스토리를 꾸미는 정도여야 한다. 굽기·타이밍·성공과 실패 없이 클릭이나 터치로 간단하게 꾸민다. 게임 자체는 중요하지 않다. 상대를 생각하며 직접 꾸미고 포장했다는 재미가 중요하다.

## 보내기와 계정

상대 링크 방문 → 빼빼로 주기 → 꾸미기·포장·카드 작성 → 인스타그램 아이디 입력 → 완성 확인 → 필요 시 카카오 로그인 → 동일 수신자 중복 확인 → 전송. 로그인 과정에서도 작성 내용을 유지하는 흐름으로 설계한다.

- 보내기는 무료다.
- 하루 제작·발송 개수 제한은 없다. 서로 다른 사람에게는 같은 날에도 보낼 수 있다. (2026년 10월 29일 변경)
- 행사 기간 동안 같은 사람에게는 한 개만 보낼 수 있다. 날짜가 바뀌어도 동일 수신자에게 다시 보낼 수 없다.
- PC와 모바일 화면을 모두 지원한다.
- 전송 전 동일 수신자에게 이미 보낸 선물이 있는지 확인한다. 이미 보냈다면 추가 전송을 막고 안내한다. 실패한 전송은 재시도할 수 있으며 중복 선물이 생성되지 않도록 한다.
- 일일 잔여 횟수·횟수 차감·자정 초기화는 사용하지 않는다. 서비스 시간대는 한국 시간 기준이다.
- 인스타그램 아이디는 직접 적는다. 계정 소유 여부를 인증하지 않는다.
- 동일인 발송 여부는 행사 내 발신자 로그인 유저 ID와 수신자 유저 ID 조합으로 식별한다. 인스타그램 아이디는 수신자에게 보여줄 입력 정보이며 중복 발송 판별 기준으로 사용하지 않는다.
- 로그인 수단은 카카오 로그인으로 정한다. 알림 이메일이 다르더라도 로그인 계정을 바꾸는 것은 아니다.
- 개인 공간은 카카오 로그인 → 이름 입력 → 고유 링크 생성·공유 흐름으로 정리했다. 공간 이름의 제약과 링크 생성 규칙은 미정이다.

## 11/11 재방문과 이메일 알림

11월 4일(11/11의 일주일 전) 배포를 목표로 한다. 사용자가 매일 방문할 것을 전제하지 않는다. 11/11에 서비스를 기억하고 돌아와 결제한 뒤 누구에게 몇 개의 빼빼로를 받았는지 확인하도록 연결하는 것이 핵심이다.

알림 채널은 이메일로 정한다. 카카오 채널 추가나 문자 발송은 현재 필수 흐름에 포함하지 않는다.

### 알림 설정

카카오 로그인 후 내 공간에서 알림 수신을 선택하고, 받을 이메일을 설정한다. 알림을 받지 않아도 서비스를 이용할 수 있다.

| 선택 | 동작 |
| --- | --- |
| 알림 수신 동의 안 함 | 이메일을 발송하지 않는다. 직접 방문해 결제·열람할 수 있다. |
| 알림 수신 동의 + ‘카카오 이메일 사용’ 체크 | 카카오에서 제공받은 이메일을 표시하고 알림 주소로 사용한다. 사용할 수 있는 주소라면 별도 입력을 생략한다. |
| 알림 수신 동의 + ‘카카오 이메일 사용’ 체크 해제 | 별도 이메일 입력란을 표시한다. 입력 주소를 인증한 뒤 알림 주소로 저장한다. |
| 카카오 이메일 미제공 또는 유효·인증 상태 확인 불가 | 직접 입력·인증 흐름으로 전환한다. |

‘카카오 이메일 사용’ 체크박스는 **주소 선택** 용도이며 **알림 수신 동의**와 구분한다. 카카오 이메일 제공 동의만으로 알림 수신 동의를 대신하지 않는다. 카카오 이메일이 반드시 @kakao.com 주소인 것은 아니다.

내 공간에서 알림 주소 변경과 수신 해제를 제공하는 흐름으로 정리했다. 직접 입력하거나 변경한 주소는 인증하며, 실패하면 수정·재시도할 수 있다. 체크박스 초기값과 이메일 인증 방식은 아직 정하지 않았다.

### 발송과 재방문

11/11 열람 시작 → 알림 대상 확인 → 열람 안내 이메일 → 링크로 내 공간 재방문 → 필요 시 카카오 로그인 → 현재 결제 상태 확인 → 미결제자는 결제, 결제 완료자는 바로 열람.

- 이메일에서는 결제 전 비공개인 개수·발신자·편지·선물 내용을 공개하지 않는다.
- 발송 실패 시 중복 발송을 방지하면서 재시도하는 흐름으로 설계한다.
- **제안, 미확정:** 수신 동의와 사용 가능한 이메일이 있고, 받은 선물이 있으며, 아직 결제하지 않은 사람에게 발송한다.
- 00:00은 결제 시작 시각이다. 이메일 발송 시각·횟수·추가 알림 여부는 별도 결정한다.

### 기존 요니버스 설정 재사용

기존 요니버스 앱과 서버에는 카카오 로그인 구현이 있다. 다만 이번 웹에서 같은 카카오 앱 설정을 재사용할 수 있는지, 웹 도메인·로그인 복귀 주소와 이메일 제공 동의 설정이 가능한지는 관리자 설정 확인이 필요하다. 기존 앱 로그인 구현이 있다는 사실만으로 웹 연동 완료로 보지 않는다.

카카오 설정 재사용과 기존 요니버스 계정·데이터 연결은 별도 결정이다. 기존 서버의 이메일 수신만으로 주소의 유효·인증 상태 확인이 충분하다고 가정하지 않는다.

## 상시 홍보와 서비스 실험

웹사이트에 요니버스 앱과 요매거진 인스타그램으로 이동하는 작은 홍보 영역을 상시 제공한다. 특정 행동 완료 시점에만 나타나는 팝업이나 완료 화면 전용 홍보가 아니다. 위치·형태·문구는 디자인 단계에서 정하며, 이벤트 경험에서 차지하는 비중은 크지 않게 한다.

이번 실험에서는 이벤트의 결제 성과와 함께 **이벤트 웹사이트를 통해 요니버스 앱 신규 가입자가 얼마나 유입되는지** 확인한다.

| 측정 항목 | 의미 |
| --- | --- |
| 이벤트 방문자 수 | 앱 가입 전환율을 계산할 기준 |
| 요니버스 앱 이동 클릭 수 | 상시 홍보를 통한 앱 관심·이동 |
| 요매거진 인스타그램 이동 클릭 수 | 공식 계정으로의 이동. 팔로우 완료 수와는 구분 |
| 이벤트 유입 앱 신규 가입자 수 | 이벤트를 통해 실제 앱 신규 가입까지 완료한 사람 |
| 이벤트 방문 → 앱 신규 가입 전환율 | 같은 측정 기간·기준으로 집계한 신규 가입자 수 / 이벤트 방문자 수 |

웹 카카오 로그인은 앱 신규 가입으로 집계하지 않는다. 기존 앱 회원의 재방문은 신규 가입과 분리하고, 신규 가입자는 중복 제외한다. 앱 설치 전후에 이벤트 유입 정보를 연결하는 방식, 가입 인정 시점, 집계 기간과 방문자 중복 제거 기준은 구현 전 결정한다. 앱 클릭만으로 신규 가입 성과를 추정하지 않는다.

결제 전 개수·발신자·편지가 그림이나 미리보기로 노출돼서는 안 된다. 다른 방문자 화면에서도 쌓인 선물이나 외관 변화로 수신 여부가 드러나서는 안 된다.

### 전송·결제 마감

- 빼빼로 보내기: 서비스 오픈부터 2026년 11월 12일 00:00 직전까지 가능하다.
- 결제: 2026년 11월 11일 00:00부터 11월 12일 00:00 직전까지 가능하다. 화면에는 “11/11 밤 11:59까지”로 안내한다.
- 서버의 한국 시간 기준으로 마감을 판단한다. 마감 후 전송·신규 결제 요청은 차단하고 종료를 안내한다. 마감 전에 꾸미기를 시작했더라도 마감 후에는 전송할 수 없다.
- 마감 후 미결제자는 신규 결제로 선물을 열 수 없다. 이미 결제한 사람의 열람을 이 마감과 함께 종료하지 않는다. 열람 종료일은 별도로 결정한다.
- 마감 직전에 시작해 마감 이후 승인되는 진행 중 결제의 처리 기준은 결제 사업자 연동 시 결정할 사항이다.

## 개인 공간 후보

캐비닛과 자물쇠, 자정까지의 카운트다운은 사용자가 제안한 후보이며 확정 디자인이 아니다. 카운트다운 종료는 무료 자동 공개가 아닌 결제 시작이다. 비용과 공개 조건을 혼동하지 않도록 안내해야 한다.

## 레퍼런스와 차별화

레퍼런스는 내 트리를 꾸며줘(https://colormytree.me/)다. 개인 공간·링크 공유·선물과 편지를 남기는 구조를 참고한다. 사용자는 소재만 바꾼 모방이라는 인상을 우려한다.

차별화의 중심은 실제 빼빼로데이에 상대를 위해 선물을 꾸미고 포장하는 문화를 디지털 경험으로 옮기는 것이다. 이름·그림·화면·문구를 독자적으로 설계하며, 결제만을 차별점으로 내세우지 않는다. 꾸미기 경험이 모방 논란이나 법적 문제를 무조건 해소한다고 단정하지 않는다.

## 학교 선택은 선택 사항 (2026-10-30)

학교 등록은 로그인·선물 전송의 필수 조건이 아니다. 선물 발신 중 카카오 로그인 후에는 작성한 선물 전송으로 복귀하고 학교 선택으로 우회시키지 않는다. 내 캐비넷의 최초 학교 선택 제안도 ‘나중에 선택하기’·닫기·Escape로 건너뛸 수 있다. 건너뛰기는 비학생 선택과 별도로 저장하며, 캐비넷 카드에서 언제든 학교를 등록할 수 있다. 미등록 사용자는 학교 인원 집계에서 제외한다. 실제 로그인 콜백 연동 시에도 학교 등록 여부로 선물 전송을 차단하지 않는다.
