# 빼빼로데이 스핀오프 웹 기획

2026년 10월 28일 대화 기준. 사용자 확정 내용과 미정 사항을 구분한다.

## 서비스와 핵심 경험

요니버스는 연애 고민 커뮤니티 앱이다. 이번 프로젝트는 특정 시즌인 빼빼로데이를 위한 이벤트성 스핀오프 웹이다. 서비스명은 미정이다.

유저마다 블로그·미니홈피 같은 개인 공간과 고유 링크를 갖는다. 지인은 링크에 방문해 빼빼로 주기를 누르고, 디지털 빼빼로를 꾸미고 포장해 짧은 편지와 함께 보낸다. 친구·호감 있는 상대·연인에게 마음을 표현한다.

베이킹이나 조리 게임이 아니다. 유저의 노력은 인스타그램 스토리를 꾸미는 정도여야 한다. 굽기·타이밍·성공과 실패 없이 클릭이나 터치로 간단하게 꾸민다. 게임 자체는 중요하지 않다. 상대를 생각하며 직접 꾸미고 포장했다는 재미가 중요하다.

## 커스텀 구성

| 항목 | 사용자 지정 범위 |
| --- | --- |
| 기본 빼빼로 | 막대, 하트 |
| 초콜릿 컬러 | 초코브라운, 핑크, 화이트초콜릿 |
| 초콜릿 토핑 | 화이트·다크·핑크 각각 네모초콜릿조각, 하트, 별 (9종) |
| 기타 토핑 | 견과류토핑, 별톡톡, 리본톡톡, 하트톡톡, 프렛첼과자 (5종) |
| 드리즐 | 화이트, 다크, 핑크 (3종) |
| 포장 | 투명비닐, 예쁜 선물상자, 꽃다발처럼 꾸민 포장 |
| 포장 장식 | 컬러별 리본. 이전 대화에서 별·하트 장식도 언급했으나 최종 구성은 추가 확인 |
| 카드 | 하트, 별, 네모, 동그라미. 컬러 약 5개 |
| 편지 | 동봉 카드에 최대 200자 |

하트 빼빼로는 가운데가 빈 하트 윤곽이며, 아래의 과자 끝 두 개가 교차하는 형태다. 속이 꽉 찬 하트나 막대 끝의 하트 사탕이 아니다. 토핑은 실제 수제 빼빼로의 먹을 수 있는 장식을 참고한다. 작은 흩뿌림, 큰 포인트 초콜릿, 얇은 드리즐 표현이 있다.

복수 토핑 선택 여부, 자유 배치 여부, 각 옵션의 상세 색상과 디자인은 아직 정하지 않았다. 참고 이미지에 등장하는 캐릭터나 꽃 등을 추가 기능으로 확정하지 않는다.

## 보내기와 계정

상대 링크 방문 → 빼빼로 주기 → 꾸미기·포장·카드 작성 → 인스타그램 아이디 입력 → 전송.

- 보내기는 무료다.
- 로그인 유저 ID 기준 하루 최대 3개를 보낸다.
- 한도는 매일 자정 초기화한다. 서비스 시간대는 한국 시간 기준으로 정리하며 구현 시 확인한다.
- 인스타그램 아이디는 직접 적는다. 계정 소유 여부를 인증하지 않는다.
- 로그인 유저 ID는 발송 한도 식별에 사용하고, 인스타그램 아이디는 수신자에게 보여줄 입력 정보다.
- 로그인 수단과 개인 공간 생성 방식은 미정이다.
- 같은 사람에게 반복 전송 가능한지는 미정이다.

## 수신 정보와 결제

| 상태 | 확인 범위 |
| --- | --- |
| 공간 주인, 결제 전 | 받은 빼빼로가 있다 / 없다만 확인 |
| 공간 주인, 결제 후 | 받은 개수, 발신자 입력 인스타그램 아이디, 메시지 카드와 꾸민 선물 등 전체 |
| 다른 방문자 | 수신 여부조차 비공개 |

결제는 11월 11일 00:00, 즉 10일에서 11일로 넘어가는 자정에 시작한다. 우선 가격은 990원이고 빼빼로데이에 한 번 결제하는 구상이다. 결제 후 새로 도착한 선물도 포함되는지는 미정이다. 운영 종료 시점도 미정이다.

결제 전 개수·발신자·편지가 그림이나 미리보기로 노출돼서는 안 된다. 다른 방문자 화면에서도 쌓인 선물이나 외관 변화로 수신 여부가 드러나서는 안 된다.

## 개인 공간 후보

캐비닛과 자물쇠, 자정까지의 카운트다운은 사용자가 제안한 후보이며 확정 디자인이 아니다. 카운트다운 종료는 무료 자동 공개가 아닌 결제 시작이다. 비용과 공개 조건을 혼동하지 않도록 안내해야 한다.

## 레퍼런스와 차별화

레퍼런스는 내 트리를 꾸며줘(https://colormytree.me/)다. 개인 공간·링크 공유·선물과 편지를 남기는 구조를 참고한다. 사용자는 소재만 바꾼 모방이라는 인상을 우려한다.

차별화의 중심은 실제 빼빼로데이에 상대를 위해 선물을 꾸미고 포장하는 문화를 디지털 경험으로 옮기는 것이다. 이름·그림·화면·문구를 독자적으로 설계하며, 결제만을 차별점으로 내세우지 않는다. 꾸미기 경험이 모방 논란이나 법적 문제를 무조건 해소한다고 단정하지 않는다.

## 제작 제약과 미정 사항

사용자가 제시한 작업 가능 시간은 약 2일이다. 복잡한 게임보다 간단한 꾸미기, 전송·저장, 로그인과 한도, 정확한 공개 범위 및 결제 처리를 우선한다. 기술 스택·배포·결제 사업자는 아직 선택하지 않았다.

남은 결정: 서비스명, 개인 공간 비주얼, 최종 일러스트 스타일, 세부 옵션과 배치 방법, 동일인 재전송, 로그인 방식, 결제 후 추가 수신 열람, 운영 종료, 기존 요니버스 계정·데이터 연결.
