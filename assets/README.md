# 이미지 탐색 자료

## 시안

concepts의 PNG 4개는 대화 중 내장 이미지 생성 도구로 만든 비교 시안이며 최종 승인되지 않았다.

- 01-heart-realistic.png: 핑크 초콜릿의 빈 하트 윤곽 빼빼로, 화이트 하트·별, 다크 조각, 드리즐.
- 02-packaged-realistic.png: 투명비닐과 핑크 리본, 아이보리 하트 카드 추가.
- 03-packaged-illustration.png: 같은 구성을 파스텔 2D 일러스트로 변환.
- 04-packaged-sticker.png: 굵고 불규칙한 외곽선, 체리핑크와 버터옐로, 단순한 스티커 감성. 사용자 미채택.

생성 방향은 위 설명과 같으며 각 파일은 완성 합성 이미지다. 투명 배경 및 실제 서비스 에셋 적합성은 구현 시 검증해야 한다.

## 사용자 참고 이미지

references/reference-01.png는 빈 하트 윤곽과 교차하는 과자 끝을 보여준다. reference-02.png부터 reference-06.png까지는 코팅·토핑·드리즐·포장의 수제 느낌을 참고하기 위한 사용자 제공 이미지다. 사용자가 보낸 참고 자료이며 서비스에 그대로 사용할 최종 자산이 아니다.
