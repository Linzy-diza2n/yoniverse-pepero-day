# 요니버스 스핀오프 웹 - 빼빼로데이

개인 링크로 디지털 빼빼로를 꾸며 선물하고, 빼빼로데이에 결제해 받은 마음을 확인하는 시즌성 웹 프로젝트입니다.

현재는 기획 및 시각 스타일 탐색 단계입니다. `cabinet-preview/`에 내 캐비넷 인터랙티브 시안을 추가했습니다. 로그인·서버·결제는 아직 연결하지 않았으며 서비스명과 최종 디자인은 미정입니다.

## 이어서 작업하기

1. 이 저장소를 회사 컴퓨터에 복제합니다.
2. Codex에서 복제한 폴더를 열고 `docs/handoff.md`와 `docs/product-plan.md`를 읽도록 요청합니다.
3. 기획 문서의 남은 결정 사항을 먼저 정리한 뒤 디자인과 구현을 시작합니다.

## 내 캐비넷 시안

`python3 -m http.server 4173 --bind 127.0.0.1 --directory cabinet-preview` 실행 후 http://127.0.0.1:4173 에서 확인합니다.

- 학교 배경 대신 취향을 담는 개인 캐비넷으로 구성했습니다.
- 이름표, 5가지 색상, 4가지 스티커를 변경하고 브라우저에 저장합니다.
- 문 여닫기 및 모바일·데스크톱 레이아웃을 제공합니다.
- 보관함과 소품은 고정 샘플입니다. 실제 수신 여부나 개수를 나타내지 않습니다.
- 초대와 선물 열람은 안내만 제공하며 계정·공유 링크·결제 연동은 없습니다.

## 통합 사이트 미리보기

`python3 -m http.server 4180 --bind 127.0.0.1 --directory cabinet-preview` 실행 후 http://127.0.0.1:4180/ 에서 시작합니다. 첫 화면은 랜딩이며 공통 하단 메뉴로 내 캐비넷, 방문자 캐비넷, 선물 만들기를 이동합니다. 내 캐비넷은 `cabinet.html`에 있습니다. 선물 만들기는 모양 선택 → 꾸미기 → 포장 순서로 연결되며 편지 단계와 실제 로그인·결제는 아직 미구현입니다.

## 나이스 학교 검색 연결

기존 정적 서버 대신 `python3 server/run.py`를 실행하고 http://127.0.0.1:4174/index.html 에서 확인합니다. 나이스에서 인증키를 발급받은 뒤 루트 `.env`에 `NEIS_API_KEY=발급받은키`를 설정하고 서버를 다시 시작하세요. 키는 서버에서만 읽으며 브라우저나 공유 링크에 포함하지 않습니다. 기존 4173 정적 서버에는 `/api/schools`가 없으므로 검색이 동작하지 않습니다.

- 학교명·줄임말 검색 → 나이스 공식 결과(최대 100개, 넓은 검색어는 더 구체적으로 입력) → 지역을 확인하고 선택.
- 저장 ID는 `neis:교육청코드:학교코드`. 예시 학교 ID는 자동 변환하지 않으며 재선택합니다.
- 현재 학교 선택은 브라우저에 저장됩니다. 실제 로그인 서버와 전체 참여자 집계는 아직 미연결입니다. 임의의 참여 숫자는 표시하지 않습니다.
- `server/schools.py`의 Memberships는 행사·검증된 사용자 ID당 한 학교만 저장합니다. 로그인 서버에서 검증한 사용자 ID와 나이스에서 검증한 학교 ID로만 호출해야 합니다. 공개된 사용자 ID 입력 API는 제공하지 않습니다.
- 인증키 미발급 상태에서는 실제 학교 검색을 검증할 수 없습니다. 키 없는 5건 샘플을 전체 검색으로 사용하지 않습니다.
- 검증: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s server -v`
